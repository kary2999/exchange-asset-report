# 示例

这 4 份是第一次实战时**手工**写的报告（快照 2026-09-29 至 2026-10-02），用来展示最终成品的结构、口径和语气。

- 它们里面的行情数字是当时的快照，**已经过期**，不要当作当前数据。
- 数字是手抄进模板的，其中的单位错误和汇总错误在验收时被抓出来改过。新流程里这些表由 `build_report.py` 从快照自动生成。
- 事实性结论（监管主体、杠杆倍数、合约数量等）也只在当时成立。

## derivatives-v2/
