最容易踩的坑

  1. 合约总数不等于市场数：尾部合约 24h 成交额不到百万美元，深度只有几万美元，滑点会很大。{I}成交分桶见上方盘点表。{I}
  2. 「指数」不等于标普或纳指：INDEX 类合约是加密指数；美股指数敞口靠 SPY、QQQ 永续，这是 ETF 价格，不是指数点位。{I}
  3. 单一来源依赖：铜和布伦特原油的指数价几乎由一个来源决定；该来源异常时，标记价与强平价会一起偏。{I}
  4. USDT 脱锚风险会通过 uindex 换算传导到指数价。{I}
  5. 周末与休市没有正股价格参照，周一开盘可能出现和周末价差很大的跳空。{I}
  6. 新闻里的杠杆倍数、合约大小和接口不一致（例如原油一张多少桶），以 App 与接口实际为准。{U}
  7. bStocks 是凭证性质的代币，不等于你在券商开户买股；可用地区和赎回权利要读发行方条款。{G}
  8. 期权是实物交割，会进入股票持仓与 Alpaca 托管，和永续的现金结算不同。{G}

仅网页转述：小体量交易所依托币安做这些业务，要满足什么条件

先说明：我读到的币安公开页面里没有找到面向外部的 TradFi 业务准入清单。{U}下面分三层：币安公开资料能查到的、币安没公开要和商务谈的、我的推论。不构成法律意见。{I}

7.1 币安公开的三条接入路径

  • Binance Link / API 返佣：用户在币安开账户并给 API Key，你用 Link ID 下单，币安按成交量返佣；支持现货、杠杆、U 本位和币本位合约，可建子账户，返佣最高 50%，有客户经理。{G}申请门槛没读到原文。{U}资料没写 TradFi 永续是否计入返佣。{U}
  • Broker Partner（早期经纪商计划）：早期计划由币安提供撮合、账户管理、结算，经纪商做用户端。{G}一份第三方教程站写过接入门槛的数字，不是币安官方口径，年代早，现在是否有效没核实，不要当门槛用，必须向币安商务确认。{U}
  • Crypto-as-a-Service（白标）：面向持牌银行、券商、交易所的整套现货加合约、流动性、托管、合规、清算，前端和品牌自己控制；要求持牌并达到规模要求，2025 年 9 月底起小范围早期接入。{G}费用和分成未披露，新闻稿只讲加密交易基础设施，没提股票或外汇等 TradFi 产品。{U}

7.2 按想做的业务，对应的条件

  • 给客户提供 TradFi 永续：自己做对手方需要衍生品牌照、资本金、保证金与强平引擎、对冲账户额度与 API 限速、7×24 风控值班；只导流则走 Link 返佣吃返佣。{I}币安对冲时你面对的是币安的深度，见第 1 节成交分桶，只有头部几个品种能承接大单，尾部品种不能当对冲腿。{I}
  • 卖股票代币：代币化证券在多数地区受证券法约束，零售发售通常需要牌照。{I}上架第三方 bStocks 要看发行方条款与可用地区，公开资料没写。{U}币安现货里 bStocks 的深度远小于对应永续，所以流动性要靠永续对冲，不要靠代币盘口。{I}
  • CFD：我在币安合约接口里没查到可对接的 CFD，通常是自己做 CFD 发行再用币安永续去对冲。{I}CFD 发行本身是强监管业务，杠杆限制、风险提示、客户适当性各地区差异大。{I}币安澳洲的 CFD 持 AFS 牌照、仅限批发客户（媒体报道）。{G}
  • 指数类产品：币安合约接口里没查到股票指数合约；自建指数需要自己的指数规则与数据授权，数据商再分发的授权不是币安能转授的。{I}可以用 SPY、QQQ 永续当替代，或用数据商价格自己合成。{I}
  • 期货（交割）与其他衍生品：币安 U 本位只有加密币的季度合约，股票和指数交割期货在 fapi、dapi 里没查到；要做就得自己做合约规则、结算价与到期交割，币安只能提供加密币的对冲腿。{I}
  • 美股现货与期权：不能依托币安直接转售；币安自己也是通过 Nest Trading 加 Alpaca。{G}你需要自己的券商通道，可以考虑直接和 Alpaca 或同类券商合作；币安这项业务不对美国用户开放。{G}

7.3 无论走哪条路都绕不开的条件（我的推论）

  • 牌照与客户范围：你对谁、在哪个司法辖区提供什么产品，决定要什么牌照；你不能借用币安的牌照。{I}
  • 客户资格与币安限制地区一致：用 Link 路径时客户要在币安开户，受币安 KYC 与限制地区约束；美国用户被排除在股票和期权产品之外。{G}
  • 对冲资金与风控：在币安开对冲账户需要 USDT 保证金，面对单一交易所对手风险；U 本位合约里有处于 SETTLING 状态的合约（见上方盘点），对冲腿要有退出预案。{I}
  • 价格源策略：你的标记价和结算价要有自己的来源，可以参考币安的多源加权设计，但不要只复制币安价格，单一来源依赖说明币安自己的价格质量也不均匀。{I}
  • 数据授权：美股行情再分发通常有交易所数据授权费用；币安公开指数价是否允许你二次商用，没查到条款。{U}
  • 休市风险：周末与盘后你的产品还在交易，币安对冲腿也在交易，但真实标的不开盘；周一跳空时双方都承担风险。{I}
  • 平台集中度：币安是否保留随时调整杠杆、费率、下架合约、限制 API 的权利，我没读条款原文，也没查到公开的 SLA。{U}
  • 规模：白标和旧经纪商计划都提规模要求，具体数字没有官方原文，必须向币安商务确认。{U}

7.4 建议的下一步（不是投资建议）

  • 先决定对客户是什么身份：只导流、做对手方、还是白标，三者所需牌照与资金差一个量级。{I}
  • 向币安商务确认：TradFi 永续是否计入 Link 返佣、白标是否开放 TradFi、对冲账户的持仓与 API 限额、指数价数据能否二次使用。{I}
  • 先用成交额排前几名的品种试点，不要一上来铺全部合约。{I}
