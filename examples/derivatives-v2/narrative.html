最容易踩的坑

  1. 合约总数不等于市场数：尾部合约 24h 成交额不到百万美元，深度只有几万美元，滑点会很大。{I}成交分桶见上方盘点表。{I}
  2. 「指数」不等于标普或纳指：INDEX 类合约是加密指数；美股指数敞口靠 SPY、QQQ 永续，这是 ETF 价格，不是指数点位。{I}
  3. 单一来源依赖：铜和布伦特原油的指数价主要由一个来源决定；该来源异常时，指数价会一起偏。标记价与强平价是否跟着偏，要看币安的标记价公式，本次没读到。{I}
  4. 按我对 uindex 的推断，USDT 脱锚风险可能通过换算传导到指数价，没验证。{I}
  5. 合约会进入结算下架：本次快照里状态为 SETTLING 的有 {{i:survey.fapi.settling_total}} 个，类型全是加密永续（PERPETUAL {{i:survey.fapi.settling_by_contract_type.PERPETUAL}} 个），TradFi 永续当前都是 TRADING。{V}TradFi 永续以后会不会下架，没有依据。{U}
  6. 周末与休市没有正股价格参照，周一开盘可能出现和周末价差很大的跳空。{I}
  7. 新闻里写的杠杆倍数、合约大小（例如原油一张多少桶），本次没从接口取到，没法对照，以 App 实际为准。{U}
  8. bStocks 是凭证性质的代币，不等于你在券商开户买股；可用地区和赎回权利要读发行方条款。{G}
  9. 期权是实物交割，会进入股票持仓与 Alpaca 托管，和永续的现金结算不同。{G}

先说明：我读到的币安公开页面里没有找到面向外部的 TradFi 业务准入清单。{U}下面分三层：币安公开资料能查到的、币安没公开要和商务谈的、我的推论。不构成法律意见。{I}

7.1 币安公开的三条接入路径

  • Binance Link / 经纪商 API：Link API 文档里有建子账户、给子账户建 API Key、调整子账户的现货与 U 本位、币本位合约佣金、查返佣记录、子账户划转等接口，覆盖现货、杠杆和这两类合约。{G}「返佣最高 50%」「有客户经理」「用 Link ID 下单」这些说法，在来源清单里的页面没找到（本次复核时币安官网页面被拦截，没读到），先当未证实。{U}申请门槛没读到原文。{U}资料没写 TradFi 永续是否计入返佣。{U}
  • Broker Partner（早期经纪商计划）：有说法称早期计划由币安提供撮合、账户管理、结算，经纪商做用户端；来源清单里没有对应页面，本次没能核实。{U}一份第三方教程站写过接入门槛的数字，不是币安官方口径，年代早，现在是否有效没核实，不要当门槛用，必须向币安商务确认。{U}
  • Crypto-as-a-Service（白标）：面向持牌银行、券商、交易所的整套现货加合约、流动性、托管、合规、清算，前端和品牌自己控制；要求持牌并达到规模要求，2025 年 9 月底起小范围早期接入，新闻稿写计划 2025 年第四季度扩大开放；现在的状态没核实。{G}费用和分成未披露，新闻稿只讲加密交易基础设施，没提股票或外汇等 TradFi 产品。{U}

7.2 按想做的业务，对应的条件

  • 给客户提供 TradFi 永续：自己做对手方需要衍生品牌照、资本金、保证金与强平引擎、对冲账户额度与 API 限速、7×24 风控值班；只导流则走 Link 返佣吃返佣。{I}币安对冲时你面对的是币安的深度，见第 1 节成交分桶，只有头部几个品种能承接大单，尾部品种不能当对冲腿。{I}
  • 卖股票代币：代币化证券在多数地区受证券法约束，零售发售通常需要牌照。{I}上架第三方 bStocks 要看发行方条款与可用地区，公开资料没写。{U}我读第 5 节价差表的印象：NVDAB、QQQB、SPYB 的现货深度明显小于对应永续，但 SMHB 的买盘深度反而比永续大，所以不能说所有 bStocks 都如此；表外的 bStocks 没测。{I}流动性大概率要靠永续对冲，不要只靠代币盘口。{I}
  • CFD：我在币安合约接口里没查到可对接的 CFD，通常是自己做 CFD 发行再用币安永续去对冲。{I}CFD 发行本身是强监管业务，杠杆限制、风险提示、客户适当性各地区差异大。{I}Finance Magnates 2022 年 7 月报道币安澳洲以 AFS 牌照向批发客户提供加密 CFD。{G}这是 2022 年的报道，现在是否仍是这样没核实。{U}
  • 指数类产品：币安合约接口里没查到股票指数合约；自建指数需要自己的指数规则与数据授权，数据商再分发的授权不是币安能转授的。{I}可以用 SPY、QQQ 永续当替代，或用数据商价格自己合成。{I}
  • 期货（交割）与其他衍生品：币安 U 本位只有加密币的季度合约，股票和指数交割期货在 fapi、dapi 里没查到；要做就得自己做合约规则、结算价与到期交割，币安只能提供加密币的对冲腿。{I}
  • 美股现货与期权：没查到币安允许外部转售这类业务的条款，我判断不能依托币安直接转售。{I}币安自己是通过 Nest Trading 加 Alpaca。{G}你需要自己的券商通道，可以考虑直接和 Alpaca 或同类券商合作；币安这项业务不对美国用户开放。{G}

7.3 无论走哪条路都绕不开的条件（我的推论）

  • 牌照与客户范围：你对谁、在哪个司法辖区提供什么产品，决定要什么牌照；你不能借用币安的牌照。{I}
  • 客户资格与币安限制地区一致：用 Link 路径时客户要在币安开户，受币安 KYC 与限制地区约束，这是我的推断，没找到明文。{I}币安的美股期权新闻稿写币安不向美国用户提供这些产品（含股票、ETF、bStocks、股票永续、期权）。{G}
  • 对冲资金与风控：在币安开对冲账户需要 USDT 保证金，面对单一交易所对手风险。{I}币安会让合约进入结算下架（见第 6 节），对冲腿要有退出预案。{I}
  • 价格源策略：你的标记价和结算价要有自己的来源，可以参考币安的多源加权设计，但不要只复制币安价格，单一来源依赖说明币安自己的价格质量也不均匀。{I}
  • 数据授权：美股行情再分发通常有交易所数据授权费用；币安公开指数价是否允许你二次商用，没查到条款。{U}
  • 休市风险：周末与盘后你的产品还在交易，币安对冲腿也在交易，但真实标的不开盘；周一跳空时双方都承担风险。{I}
  • 平台集中度：币安是否保留随时调整杠杆、费率、下架合约、限制 API 的权利，我没读条款原文，也没查到公开的 SLA。{U}
  • 规模：白标和旧经纪商计划都提规模要求，具体数字没有官方原文，必须向币安商务确认。{U}

7.4 建议的下一步（不是投资建议）

  • 先决定对客户是什么身份：只导流、做对手方、还是白标，三者所需牌照与资金差一个量级。{I}
  • 向币安商务确认：TradFi 永续是否计入 Link 返佣、白标是否开放 TradFi、对冲账户的持仓与 API 限额、指数价数据能否二次使用。{I}
  • 先用成交额排前几名的品种试点，不要一上来铺全部合约。{I}
