  • 在本次扫描的合约接口里，美股指数的敞口只看到 SPY、QQQ、IWM 这类 ETF 的永续，价格是 ETF 的价格，不是指数点位。推论

  • 指数价：接口 constituents 给出合约的成分来源和权重，见下表；币安自己盘口权重不大，大头是数据商（dxFeed、Kaiko、Pyth Pro、Massive 等）。铜和布伦特原油是例外，大头是 RedStone 或 Hyperliquid，见下面的单一来源依赖。实测

  • 代号带 xyz: 前缀的来源（如 xyz:GOLD），我推断是 Hyperliquid 上第三方部署的市场，也就是另一家永续的价格，不是传统交易所报价。推论

  • 标记价公式和休市（周末）定价规则，本次没有读到币安公告原文，不写具体机制。未证实
  • 接口的合约信息里有 PERCENT_PRICE 过滤器和 marketTakeBound 字段，具体含义我按字段名理解，没读文档确认。未证实

7.3 无论走哪条路都绕不开的条件（我的推论）

  • 牌照与客户范围：你对谁、在哪个司法辖区提供什么产品，决定要什么牌照；你不能借用币安的牌照。推论
  • 客户资格与币安限制地区一致：用 Link 路径时客户要在币安开户，受币安 KYC 与限制地区约束，这是我的推断，没找到明文。推论币安的美股期权新闻稿写币安不向美国用户提供这些产品（含股票、ETF、bStocks、股票永续、期权）。转述
  • 对冲资金与风控：在币安开对冲账户需要 USDT 保证金，面对单一交易所对手风险。推论币安会让合约进入结算下架（见第 6 节），对冲腿要有退出预案。推论
  • 价格源策略：你的标记价和结算价要有自己的来源，可以参考币安的多源加权设计，但不要只复制币安价格，单一来源依赖说明币安自己的价格质量也不均匀。推论
  • 数据授权：美股行情再分发通常有交易所数据授权费用；币安公开指数价是否允许你二次商用，没查到条款。未证实
  • 休市风险：周末与盘后你的产品还在交易，币安对冲腿也在交易，但真实标的不开盘；周一跳空时双方都承担风险。推论
  • 平台集中度：币安是否保留随时调整杠杆、费率、下架合约、限制 API 的权利，我没读条款原文，也没查到公开的 SLA。未证实
  • 规模：白标和旧经纪商计划都提规模要求，具体数字没有官方原文，必须向币安商务确认。未证实

7.4 建议的下一步（不是投资建议）

  • 先决定对客户是什么身份：只导流、做对手方、还是白标，三者所需牌照与资金差一个量级。推论
  • 向币安商务确认：TradFi 永续是否计入 Link 返佣、白标是否开放 TradFi、对冲账户的持仓与 API 限额、指数价数据能否二次使用。推论
  • 先用成交额排前几名的品种试点，不要一上来铺全部合约。推论
